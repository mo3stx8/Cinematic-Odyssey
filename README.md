# 🎬 Cinematic Odyssey

A visually immersive **cinematic landing page** built using HTML, CSS, and JavaScript.
This project focuses on creating smooth animations and a cinematic user experience for modern web interfaces.

## ✨ Features

* 🎥 Cinematic visual design
* ✨ Smooth animations and transitions
* 🖱️ Interactive UI elements
* 📱 Responsive layout
* ⚡ Lightweight and fast
* 🧩 Easy to customize

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
